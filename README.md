# FitLog — Workout Library

FitLog is a responsive workout library web application where users can explore different workouts, view detailed exercise information, create a daily workout plan, and save workouts for later.

**Live Website:** https://6th-assignment-flax.vercel.app/

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI

## Key Features

- Browse a workout library with different exercises.
- View detailed information about each workout.
- Add up to five workouts to today's plan.
- Save workouts for later.
- Track total exercises, workout duration, and calories.
- Mark workouts as completed.
- Remove workouts from today's plan or saved list.
- Sort workouts by duration, calories, and rating.
- Responsive design for mobile, tablet, and desktop.

## Dependencies

Main project dependencies:

- **next** — React framework for the application.
- **react** — UI development library.
- **react-dom** — React DOM rendering.
- **react-toastify** — Toast notifications.
- **tailwindcss** — Utility-first CSS framework.
- **daisyui** — Tailwind CSS component library.
- **typescript** — Static type checking.

## Run Locally

Follow these steps to run FitLog on your local machine.

**1. Clone the repository**

Open CMD and run:

```bash
https://github.com/MahabubMabba/6th-Assignment
```

**2. Navigate to the project folder**

```bash
cd fit-log
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit the following URL in your browser:

```text
http://localhost:3000
```
